Try it in your browser

Magenta in your browser is the same chat interface as magenta web (the local browser UI, coming in the next release), running entirely in this page with your own API key (OpenAI, Anthropic, OpenRouter, Google Gemini) or your own endpoint URL and key. Requests go from your browser directly to the provider you choose; nothing is sent to Magenta's servers (there are none). Keys stay in the tab's memory unless you ask the page to remember them on your device.

It keeps what makes Magenta useful: a conversation tree with fork, clone and labels, any provider or your own endpoint in one interface, token and prompt-cache statistics for every answer, and export (session JSONL that opens in the CLI, or a self-contained HTML file) and import. Web search uses the provider's own search where it has one, or Tavily with your key. It cannot touch your computer: for ChatGPT plan sign-in, local tools that read and edit your project, Packages and memory, install the CLI below.

Install on macOS or Linux

bootstrap="$(mktemp)"
curl -fsSL https://raw.githubusercontent.com/Minions-Land/Magenta-CLI/main/install.sh -o "$bootstrap"
bash "$bootstrap"
rm -f "$bootstrap"

The bootstrap resolves the latest release, checks the installer's digest, and installs the executable and its resources after verifying them against the release's SHA256SUMS. For Windows (PowerShell), networks in mainland China, and manual verification, follow the install guide.

First steps

cd /path/to/your/project
magenta

Inside Magenta, type /login to sign in or add an API key, /api add <name> <url> to use your own endpoint, and /model to pick a model. magenta --help lists every option.

Shared sessions

The session viewer shows a Magenta session export that someone shared as a GitHub gist. It loads the gist from GitHub in your browser and shows it in an isolated frame; the content comes from the person who shared it.

Model catalog

Magenta keeps its model list current from the public model catalog on this site. The files are generated from the model data built into the release and contain nothing beyond it; Magenta verifies each file's digest, never waits for it at startup, and makes no request with --offline.
